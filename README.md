# Serial-Terminal

A web-based UART serial terminal built with React and the Web Serial API.  
This application allows users to connect to serial devices directly from the browser, send and receive data, and monitor communication in real-time.

Developed as the final project for my Bachelor's degree in Computer Engineering.

## Features

- **Web Serial API Integration**: Communicate with serial devices without additional software.
- **Real-Time Data Monitoring**: View incoming and outgoing serial data instantly.
- **User-Friendly Interface**: Clean and intuitive design for easy interaction.
- **Configurable Settings**: Adjust baud rate and other serial parameters.

## Getting Started

### Prerequisites

- **Node.js**: Download from [https://nodejs.org/](https://nodejs.org/)
- **Supported Browser**: Use a Chromium-based browser like Chrome or Edge that supports the Web Serial API.

### Installation

1. Clone the Repository
2. Install Dependencies
3. Start the Development Server

Usage

    Connect to a Serial Device:

        Click on the "Connect" button.

        Select the desired serial port from the prompt.

        Set the appropriate baud rate and other configurations.

    Send Data:

        Type your message into the input field.

        Press "Enter" or click "Send" to transmit the data.

    Receive Data:

        Incoming data from the connected device will appear in the terminal window in real-time.
